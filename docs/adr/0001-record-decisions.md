# 0001. Record decisions as ADRs

- **Status:** accepted
- **Date:** 2026-10-19

## Context

The reasons behind the suite's shape get lost in code comments and commit messages.

## Decision

A decision a newcomer could undo by mistake gets a short ADR from [0000-template.md](0000-template.md); code comments keep one line of why.

## Consequences

A decision changes by superseding its ADR, not by quietly editing code.
